  <name>Task 1: Run automated curl pre-checks against live server</name>
  <files></files>
  <action>
Before the human checkpoint, run automated curl pre-checks to surface obvious failures early.

The server cannot be started by Claude during task execution. Print the following instruction for the user to run in a separate terminal before proceeding:

```
Start the server in a separate terminal:
  conda activate rental-search && uvicorn main:app --reload
```

Then run the following curl sequence and capture output:

**Check 1 — POST /search:**
```bash
RUN_ID=$(curl -s -X POST http://localhost:8000/search \
  -H "Content-Type: application/json" \
  -d '{"query": "2 bed apartment in Richmond VIC under 600000"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['run_id'])")
echo "run_id: $RUN_ID"
```

**Check 2 — GET /stream with 20 second timeout (observe events):**
```bash
curl -N --max-time 20 "http://localhost:8000/stream/$RUN_ID"
```
Expected: lines starting with `event: thinking`, `event: tool_call`, `event: tool_result`, and eventually `event: complete`.

**Check 3 — CORS preflight:**
```bash
curl -i -X OPTIONS http://localhost:8000/stream/$RUN_ID \
  -H "Origin: http://localhost:3000" \
  -H "Access-Control-Request-Method: GET"
```
Expected: Response contains `Access-Control-Allow-Origin: *`.

**Check 4 — 409 Conflict:**
```bash
curl -s -X POST http://localhost:8000/search \
  -H "Content-Type: application/json" \
  -d '{"query": "another query"}' | python3 -m json.tool
```
Expected: `{"detail": "A search is already in progress"}` with HTTP 409.

Record outputs from all four checks for the human checkpoint.

  <how-to-verify>
With the server running (uvicorn main:app --reload in a separate terminal):

**1. Verify POST /search returns run_id (API-01):**
```bash
RUN_ID=$(curl -s -X POST http://localhost:8000/search \
  -H "Content-Type: application/json" \
  -d '{"query": "2 bed apartment in Richmond VIC under 600000"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['run_id'])")
echo "run_id: $RUN_ID"
```
Expected: A UUID like `a3f7c1d2-...`

**2. Verify SSE stream emits typed events (API-02, API-03):**
```bash
curl -N --max-time 30 "http://localhost:8000/stream/$RUN_ID"
```
Expected: Live output of SSE lines — you should see:
- `event: thinking` with `data: {"type": "thinking", "text": "..."}`
- `event: tool_call` with `data: {"type": "tool_call", "tool": "browser_navigate", ...}`
- `event: tool_result` with `data: {"type": "tool_result", ...}`
- Eventually `event: complete` with `data: {"type": "complete", "count": N, "listings": [...]}`

**3. Verify disconnect cancels agent (API-04):**
Run a new search, then use --max-time 5 to disconnect early:
```bash
RUN_ID2=$(curl -s -X POST http://localhost:8000/search \
  -H "Content-Type: application/json" \
  -d '{"query": "house in Fitzroy"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['run_id'])")
curl -N --max-time 5 "http://localhost:8000/stream/$RUN_ID2"
```
Check the server terminal log. Expected: A log line containing "cancelled" or "Agent task cancelled for run".

**4. Verify CORS headers (API-05):**
```bash
curl -i -X OPTIONS "http://localhost:8000/stream/$RUN_ID" \
  -H "Origin: http://localhost:3000" \
  -H "Access-Control-Request-Method: GET"
```
Expected: Response contains `access-control-allow-origin: *`

All four checks must pass.
