**HTML escape helper** (required — listing data comes from LLM output):
```javascript
function esc(str) {
  return String(str ?? '').replace(/&/g,'&amp;').replace(/</g,'&lt;').replace(/>/g,'&gt;').replace(/"/g,'&quot;');
}

function safeUrl(url) {
  if (!url) return null;
  return String(url).startsWith('https://') ? url : null;
}
```

**`setSearching(query)`** — transition to searching state:
- `queryInput.disabled = true; searchBtn.disabled = true; spinner.classList.remove('hidden');`
- Show `banner`, set `bannerText.textContent = 'Searching for: "' + query + '"';`
- Show `stepLog`, clear it: `stepLog.innerHTML = '';`
- Hide `errorBanner`, `resultsSection`

**`setIdle()`** — re-enable form:
- `queryInput.disabled = false; searchBtn.disabled = false; spinner.classList.add('hidden');`
- Hide `banner`, `stepLog`

**`showError(msg)`** — display error banner and return to idle:
- `errorBanner.textContent = msg; errorBanner.classList.remove('hidden');`
- Call `setIdle()`

**`appendStepLine(tool, label)`** — add a new line to the step log:
- Create `<div class="flex items-center gap-1.5 py-0.5">` containing the label text
- Map tool name to icon prefix: `browser_navigate` → `"🔍 "`, `browser_take_screenshot` → `"📸 "`, `browser_wait_for` → `"⏳ "`, default → `"• "`
- Set element text to icon + label (use `esc(label)` if injecting via innerHTML, or textContent if plain text)
- `stepLog.appendChild(el); stepLog.scrollTop = stepLog.scrollHeight;`
- `lastStepEl = el;`

**`appendTickToPreviousLine(success)`**:
- If `!lastStepEl` return early
- Create `<span class="...">` with text `success ? ' ✓' : ' ✗'`, class `text-green-600` or `text-red-500`
- `lastStepEl.appendChild(tick);`

**Error message map**:
```javascript
const ERROR_MESSAGES = {
  BotDetectedError: 'Domain.com.au blocked the search. Try again in a moment.',
  StepLimitError:   'The search took too long. Try a more specific query.',
  MCPError:         'Something went wrong. Check the server is running.',
  UnknownError:     'Something went wrong. Check the server is running.',
  connection:       'Lost connection to the server. Please try again.',
  conflict:         'A search is already in progress. Please wait.',
};
```

**`handleSubmit(event)`** — the main submit handler:
1. `event.preventDefault(); const query = queryInput.value.trim(); if (!query) return;`
2. Close any previous stream: `if (currentEs) { currentEs.close(); currentEs = null; }`
3. `setSearching(query);`
4. Inside `try/catch`:
   - `const res = await fetch('/search', { method: 'POST', headers: {'Content-Type':'application/json'}, body: JSON.stringify({query}) });`
   - `if (!res.ok)` → check `res.status === 409`, show `ERROR_MESSAGES.conflict` or `ERROR_MESSAGES.UnknownError`, call `setIdle()`, return
   - `const { run_id } = await res.json();`
   - `currentEs = new EventSource('/stream/' + run_id);`
   - `currentEs.addEventListener('tool_call', (e) => { const d = JSON.parse(e.data); appendStepLine(d.tool, d.label); });`
   - `currentEs.addEventListener('tool_result', (e) => { const d = JSON.parse(e.data); appendTickToPreviousLine(d.success); });`
   - `currentEs.addEventListener('complete', (e) => { currentEs.close(); currentEs = null; const d = JSON.parse(e.data); renderResults(d); });`
   - `currentEs.addEventListener('error', (e) => { currentEs.close(); currentEs = null; const d = JSON.parse(e.data); showError(ERROR_MESSAGES[d.error_type] ?? ERROR_MESSAGES.UnknownError); });`
   - `currentEs.onerror = () => { if(currentEs){currentEs.close(); currentEs=null;} showError(ERROR_MESSAGES.connection); };`
5. Catch block: `showError(ERROR_MESSAGES.connection);`

**`renderResults(data)`** — stub only in this plan, full implementation in Plan 02:

**Wire form**: `form.addEventListener('submit', handleSubmit);`

**Critical constraints to honour:**
- `addEventListener('complete', ...)` NOT `onmessage` — typed events never fire on onmessage
- `es.close()` called in BOTH complete AND error handlers — prevents auto-reconnect
- 409 checked at fetch() level BEFORE reading run_id
- `tailwind.config` is synchronous in `<head>` after CDN — already done in Task 1
