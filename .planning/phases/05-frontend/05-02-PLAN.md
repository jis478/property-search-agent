**`renderResults(data)`**:
The `complete` SSE event payload shape (from api/search.py `make_complete()`):
```
{ type, run_id, listings: [{address, price, bedrooms, bathrooms, property_type, listing_url}], count, partial }
```

Implementation:

2. Call `setIdle()` to re-enable form.
3. Show `resultsSection` (remove `hidden`).
4. Clear `cardGrid.innerHTML = '';`, hide `noResults`, hide `resultsWarning`.
5. If `data.partial === true`, show `resultsWarning` with text: `"Some results may be incomplete — Domain.com.au may have partially blocked the search."`.
6. If `data.count === 0` or `data.listings.length === 0`, show `noResults` (add class `hidden` to cardGrid, remove from noResults) and return.
7. Otherwise, for each listing in `data.listings`, call `buildCardHTML(listing)` and append to `cardGrid`.

**`buildCardHTML(listing)`** — returns an HTML string inserted via `insertAdjacentHTML`. All user-facing strings from the listing must be escaped with `esc()`. The `listing_url` must pass `safeUrl()` before use in `href`.

Card structure (Tailwind classes per locked decisions):
```javascript
function buildCardHTML(listing) {
  const price = listing.price
    ? `<p class="text-green-600 text-lg font-semibold">${esc(listing.price)}</p>`
    : `<p class="text-gray-400 text-sm italic">Price on application</p>`;

  const metaParts = [];
  if (listing.bedrooms  != null) metaParts.push(`${esc(String(listing.bedrooms))} bed`);
  if (listing.bathrooms != null) metaParts.push(`${esc(String(listing.bathrooms))} bath`);
  if (listing.property_type)     metaParts.push(esc(listing.property_type));
  const meta = metaParts.length
    ? `<p class="text-sm text-gray-500">${metaParts.join(' · ')}</p>`
    : '';

  const url = safeUrl(listing.listing_url);
  const cta = url
    ? `<a href="${url}" target="_blank" rel="noopener noreferrer"
          class="mt-auto block text-center border border-green-600 text-green-600
                 rounded-lg px-3 py-2 text-sm font-medium hover:bg-green-50 transition-colors">
          View on Domain &rarr;</a>`
    : '';

  return `
    <div class="bg-white rounded-xl shadow-sm border border-gray-100 p-4
                flex flex-col gap-2 animate-fade-in">
      <p class="font-semibold text-gray-900 leading-snug">${esc(listing.address)}</p>
      ${price}
      ${meta}
      ${cta}
    </div>`;
}
```

Append each card: `cardGrid.insertAdjacentHTML('beforeend', buildCardHTML(listing));`

**Constraints:**
- `bedrooms != null` (not `!listing.bedrooms`) — bedrooms could be `0`, which is falsy but valid
- `property_type` uses `if (listing.property_type)` — empty string is falsy and should be omitted
- `listing_url` in href must go through `safeUrl()` — prevents `href="null"` and open-redirect if LLM hallucinates a non-https URL
- All text content through `esc()` — prevents XSS from LLM-generated address strings
- Cards get `animate-fade-in` class — Tailwind config registered this in Plan 01's Task 1; if it doesn't animate, check that `tailwind.config` block is in `<head>` synchronously
