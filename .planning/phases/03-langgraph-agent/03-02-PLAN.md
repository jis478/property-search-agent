<task type="auto">
  <name>Task 2: System prompt</name>
  <files>agent/prompts.py</files>
  <action>
    Create `agent/prompts.py` with a SYSTEM_PROMPT string. The prompt must satisfy all these constraints:

    1. Tool restriction — explicitly list exactly three allowed tools: browser_navigate, browser_take_screenshot, browser_wait_for. Instruct the agent NOT to use any other tools.

    2. Page iteration — instruct to navigate to the URL, wait 2 seconds, take a screenshot, then repeat for page 2 and page 3 by appending `?page=2` and `?page=3` to the base URL.

    3. Output format — instruct the agent to output a JSON object as its FINAL message (not as a tool call):
       {"bot_detected": false, "listings": [...]}
       or if a bot-challenge/CAPTCHA page is detected:
       {"bot_detected": true, "listings": []}

    4. Listing fields — for each listing, extract: address (full street address), listing_url (construct from visible listing ID or use the page URL + listing path if visible), price (as displayed text, e.g. "$450 pw", or null), bedrooms (integer or null), bathrooms (integer or null), property_type ("house", "apartment", "townhouse", etc. or null).

    5. Minimum viable listing — include listings where at least address is visible; listing_url may be null if not determinable from the screenshot (the parser will filter out truly invalid ones).

    6. Bot detection — instruct the LLM to recognize bot-challenge pages by these visual cues: CAPTCHA widget, "Verify you are human" text, "Please verify" text, or absence of any property listing cards. Set bot_detected=true immediately on detection; do not attempt further scraping.

    7. Step budget hint — remind the agent it has a limited number of steps and should work efficiently: navigate → wait → screenshot → extract, for each of the 3 pages, then return JSON.

    Write the prompt as a triple-quoted string assigned to SYSTEM_PROMPT. Make it clear and directive — the agent should not need to improvise. The exact wording is Claude's Discretion but all seven constraints above must be reflected.
  </action>
  <verify>
    `conda run -n rental-search python -c "from agent.prompts import SYSTEM_PROMPT; assert 'browser_navigate' in SYSTEM_PROMPT; assert 'browser_take_screenshot' in SYSTEM_PROMPT; assert 'bot_detected' in SYSTEM_PROMPT; assert 'listings' in SYSTEM_PROMPT; print('OK')"` prints OK.
    Review SYSTEM_PROMPT manually: confirm it mentions page 1, 2, 3 and JSON output format.
  </verify>
  <done>SYSTEM_PROMPT is importable, references all three allowed tools, includes JSON output format with bot_detected flag, and covers 3-page iteration.</done>
</task>
